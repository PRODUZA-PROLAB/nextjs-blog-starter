O **v1.0.0** entrega o núcleo do blog. Veja o que vem por aí nas próximas
versões.

## Já implementado

- [x] Listagem de posts em MDX com frontmatter
- [x] Páginas de categoria e busca
- [x] Tema claro/escuro persistente
- [x] RSS, sitemap e robots.txt
- [x] SEO básico com Open Graph e Twitter Cards
- [x] Testes com `node:test`

## Planejado

- [ ] Paginação para listagens longas
- [ ] Comentários (discussions ou remark42)
- [ ] Tags dedicadas (além de categorias)
- [ ] Suporte a imagens de capa com `next/image`
- [ ] View Transitions API
- [ ] Internacionalização (i18n)
- [ ] Lighthouse CI no fluxo de build

## Contribua

O starter é feito para ser um ponto de partida: as libs são puras e testadas,
o CSS é variável de tema e a estrutura de `app/` segue as convenções do App
Router. Sinta-se livre para bifurcar e adaptar.

Fique de olho no [feed RSS](/rss.xml) para acompanhar as novidades.
